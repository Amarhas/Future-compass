# Accessibility

Future Compass should be usable by children on phones, including children with different reading, attention, motor, or visual needs.

## Current priorities

- Mobile-first layout
- Large tap targets
- Clear focus states
- Theme selector
- High Contrast theme
- Minimal reading load
- One clear action at a time
- No meaning conveyed by color alone

## Interaction rules

- Buttons should be easy to tap with a thumb.
- Text should stay readable on small screens.
- Modals should have clear labels and obvious exits.
- Activity instructions should be short and direct.
- The Start Here module should reduce friction, not add a pre-lesson.

## Content accessibility

Avoid wording that feels like testing, grading, or diagnosis.

Prefer:

> Try this small challenge.

Avoid:

> Complete this assessment.

Prefer:

> Pick how you want to start today.

Avoid:

> Choose your learning style.

## Future checks

Before each stable checkpoint, test:

- keyboard navigation
- mobile tap targets
- contrast in each theme
- screen reader labels for modals
- reduced motion option if animations are added
- readability at phone widths
