# Privacy and Safety

Future Compass is currently a public GitHub repository. Documentation must be useful for project continuity without exposing private personal context.

## Public repo rule

Do not commit the user's private thoughts, personal reflections, raw pondering, mental state, or sensitive life context to this repository.

Allowed:

- Product decisions
- Technical rationale
- Sanitized project insights
- Public-safe design constraints
- Factual version history
- Known bugs and implementation notes
- User-approved requirements stated as project requirements

Not allowed:

- Raw personal reflections
- Private headspace
- Therapy-like or emotional processing notes
- Sensitive family, health, finance, legal, or identity context
- Long-form conversational digests that reveal the user's inner reasoning
- Anything that would feel invasive if the repository were viewed by a stranger

## Sanitized continuity model

Use this format:

> Decision: Badges should represent evidence of practice, not fixed identity labels.

Avoid this format:

> The user felt/thought/worried privately about ...

## Session digests

Session digests in this repo must be technical and product-focused. They may include:

- what changed
- why the product direction changed
- what technical constraints were discovered
- what a future maintainer needs to know

They must not include private reflections or raw conversation texture.

## Adult gate safety note

The adult gate is only a local separation boundary. It is not authentication, encryption, or privacy protection.

## Child-facing safety note

The app should avoid deterministic labels such as:

- You are a future engineer
- You are a visual learner
- This is your career path

Prefer reversible, evidence-based language:

- You have Builder evidence
- Try another design challenge
- This badge shows practice, not a permanent label
