# ADR-0002: Badges Represent Practice Evidence

## Status

Accepted

## Decision

Future Compass badges will represent practice evidence gathered through completed activities and reflections. They should not be presented as permanent labels.

## Reason

The product is intended to support exploration without pressure. Badge evidence can help children and grown-ups notice useful patterns while keeping future options open.

## Consequences

- Badge copy should use flexible language.
- Reports should describe evidence and practice, not destiny or fixed identity.
- Badge levels can grow through activity evidence.
- Badge data should eventually be stored as evidence records, not only calculated counts.

## Safe to touch

Conditional. Badge names, paths, and scoring can be refined, but the practice-evidence rule should remain stable unless explicitly revisited.
