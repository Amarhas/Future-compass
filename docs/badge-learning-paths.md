# Badge Learning Paths

Future Compass badges are learning benchmarks. They are designed to show practice and reflection over time, not to assign a fixed identity to a child.

## Badge philosophy

A badge means:

> I practiced this kind of work, reflected on it, and built evidence over time.

A badge does not mean:

> This is what I am forever.

## Levels

| Level | Meaning |
|---|---|
| Locked | No evidence yet |
| Starter | Tried one related activity |
| Explorer | Repeated or liked a related activity |
| Builder | Showed sustained evidence or interest |
| Guide | Ready for a teach/help/share challenge |

## Example: Builder path

| Step | Benchmark |
|---|---|
| 1 | Try one building challenge |
| 2 | Improve the design after testing |
| 3 | Explain how the design works |
| 4 | Help someone else build something |

## Badge categories

Initial badge categories:

- Builder
- Fixer
- Investigator
- Planner
- Organizer
- Helper
- Leader
- Observer
- Explainer
- Creator
- Teammate

## Design rule

Badge language should remain encouraging and reversible. Avoid labels like "You are a future engineer." Prefer language like:

> You have strong Builder evidence. Try another design challenge and explain how it works.

## Long-term use

Badge paths can eventually connect to:

- skill evidence
- project portfolios
- mentor conversations
- age-specific learning tracks
- career exposure activities
- school/counselor discussions
