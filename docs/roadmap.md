# Future Compass Roadmap

## Current state

The repository is initialized with the Future Compass concept, checkpoint documentation, and badge learning path documentation.

## Near-term goals

### v0.4.2 — Preserve local-safe prototype

- Preserve the colorful single-file local-safe build
- Keep adult gate separation
- Keep badge evidence philosophy
- Keep mobile-first layout and accessibility direction

### v0.5 — PWA build

Goal: move from local prototype to installable mobile web app.

Planned work:

- Add `manifest.webmanifest`
- Add service worker
- Add offline caching
- Add app icons
- Prepare for GitHub Pages or other static hosting
- Keep local-first storage
- Preserve child-friendly colorful UI

### v0.6 — Android packaging option

Two possible paths:

1. **TWA wrapper** if the app is hosted as a trusted PWA.
2. **Capacitor wrapper** if the app should be bundled as a local Android app.

## Design principles

- Mobile-first
- Accessible tap targets
- High-contrast theme available
- Low reading load for children
- One clear action at a time
- Badges represent practice evidence, not permanent identity
- Adult interpretation is separated from the child flow
- No unnecessary account system until the product need is proven

## Future features

- Multiple child profiles
- Badge-specific challenge tracks
- Parent/counselor export reports
- Optional PWA install flow
- Optional cloud sync only after privacy model is defined
- Expanded age tracks: 10–12, 13–15, 16–18
